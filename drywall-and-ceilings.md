# Drywall and ceilings

Measured the way a drywall and ceiling contractor prices it. Worked example: [Dane County takeoff](https://github.com/Grishutov/takeoff-samples#6-drywall-and-ceilings---public-office-fit-out-madison-wi).

## Read first
- [ ] Partition type schedule: board layers on each side, stud size, gauge and spacing, insulation, fire and sound rating.
- [ ] Wall heights for each type: to the underside of the deck, or to the ceiling plus a stated amount. Take them from sections and the type schedule, not from the plan.
- [ ] Reflected ceiling plan and finish schedule: ceiling type and height for every room.
- [ ] Door schedule: sizes for deductions.
- [ ] What is not yours: existing walls to remain, shaft walls by others, glazed partitions.

## Partitions
- [ ] Measure each run along its centreline, by type. Tag the run ID on the markup.
- [ ] Board area = length x height x faces x layers. Keep faces and layers as separate columns, so a change in type updates everything.
- [ ] Deduct openings by your stated rule, on every face and every layer.
- [ ] Track = run length for the top and for the bottom of each stud row.
- [ ] Studs: from spacing, plus extras at openings, corners and ends. State the method.
- [ ] Insulation where the type calls for it: length x height.
- [ ] Corner bead, trims and control joints from the markup counts.
- [ ] Soffits, bulkheads, furring, column wraps and shaft walls as separate lines.

## Ceilings
- [ ] Measure room by room, by ceiling type.
- [ ] Acoustic tiles: area divided by tile size, plus waste.
- [ ] Grid for a 2 x 4 or 2 x 2 layout: main tees at 4 ft centres, cross tees from the module, wall angle = room perimeter.
- [ ] Hanger wires: typically one per 16 SF (4 ft along the mains). Check the specification or manufacturer.
- [ ] Light fittings sit in the grid: no deduction from the tile area, but note it.
- [ ] GWB ceilings and bulkheads with their framing as separate lines.

## Check
- [ ] Total partition length against half the total length of all wall face lines on the plan.
- [ ] Ceiling areas room by room against one outline of the floor. The difference should be close to the wall footprint.
- [ ] Doors deducted = doors in the schedule for the measured area.

## Deliver
- [ ] Excel by partition type with run IDs, live formulas and a summary of materials.
- [ ] Colour PDF markup.
- [ ] Query list, assumptions (heights, deductions, waste) and exclusions.
