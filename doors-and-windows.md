# Doors and windows

Counts that agree with the schedule, plus the items other trades take from them.

## Read first
- [ ] Door and window schedules: type, size, fire rating, hardware set, glazing.
- [ ] Plans of every level and the elevations.

## Measure
- [ ] Count each type on the plans with a tag on the markup.
- [ ] Compare plan counts with the schedule. Every difference becomes a query.
- [ ] Sizes: note whether the schedule gives the leaf, the frame or the structural opening.
- [ ] Frames, sills, lintels and ironmongery sets per opening.
- [ ] Glazing area by type where glazing is priced separately.

## Items other trades need
- [ ] Opening areas for wall deductions (drywall, painting, masonry, cladding).
- [ ] Door widths for skirting deductions.
- [ ] Counts of doors for painting, both faces.

## Deliver
- [ ] Count by type and level, with the plan reference for each opening.
- [ ] Differences between plans and schedule, as queries.
