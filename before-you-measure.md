# Before you measure

Most takeoff errors start before the first line is measured: an old revision, a sheet that is not to scale, a scope nobody confirmed. Twenty minutes on this list saves hours later.

## The drawing set
- [ ] Get the full set, not only the sheets for your trade. Sections, details and schedules change quantities.
- [ ] Get the drawing issue list and check the revision of every sheet you use. Note superseded sheets.
- [ ] Get the specification and any addenda. Addenda often change types and heights.
- [ ] Read the general notes and legends on every discipline before measuring.

## Scale
- [ ] Check the scale on every sheet you measure against a printed dimension, in both directions.
- [ ] Check a second, long dimension. A PDF printed "fit to page" is off by a few percent everywhere.
- [ ] Note sheets marked "not to scale" and measure from dimensions there.
- [ ] Prefer the PDF vector linework or the DWG over scaling by eye.

## Scope
- [ ] Confirm what to measure and in what format: the client's template, units, measuring rules.
- [ ] Confirm what is by others: existing to remain, MEP shafts, specialist packages.
- [ ] Confirm waste allowances: in the quantity, in the rate, or not at all. Never in both.

## Queries
- [ ] Start a query list on day one: missing dimensions, plan and schedule that disagree, referenced sheets that are missing.
- [ ] Give every query a number, the sheet and the grid. Write your assumption next to it, so measuring can continue.
- [ ] Send the first queries early. Answers take days.

## Markup
- [ ] Choose one colour per item before you start and put the legend on the first sheet.
- [ ] Give every measured run or area an ID that appears in the Excel line.
