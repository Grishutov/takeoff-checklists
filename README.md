# Takeoff checklists

The checklists I go through on every quantity takeoff, trade by trade. They come from 11+ years in construction: first as a construction surveyor and head of a survey department, now as a quantity surveyor.

Each list has four parts: what to read before measuring, how to measure, how to check the result, and what to deliver. Measuring rules differ between contracts (NRM2, CESMM, a contractor's own format), so where a rule matters the list says "state it" instead of giving one answer.

| Checklist | Use it for |
| --- | --- |
| [Before you measure](before-you-measure.md) | Any job: drawing set, revisions, scale, scope, the first queries |
| [Drywall and ceilings](drywall-and-ceilings.md) | Partitions by type, GWB, framing, insulation, ACT and grid |
| [Painting and finishes](painting-and-finishes.md) | Walls, ceilings, doors, trims, floors and skirting, room by room |
| [Concrete](concrete.md) | Foundations, slabs, frame, formwork and rebar allowances |
| [Structural steel](structural-steel.md) | Member lists by mark, weights, allowances, coatings |
| [Doors and windows](doors-and-windows.md) | Counts by type, schedule against plans, items other trades need |
| [Earthworks](earthworks.md) | Survey and grading design to cut and fill volumes |
| [Checking a BoQ](checking-a-boq.md) | Checking someone else's quantities against the drawings |

Worked examples of these lists are in [takeoff-samples](https://github.com/Grishutov/takeoff-samples), for example drywall and ceilings on a real public bid set (686 LF of partitions in 9 types, 15 queries to the client).
